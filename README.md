# Endless

เกมขับรถชมวิวแบบไม่มีจุดสิ้นสุด ทุกอย่างบนจอวาดด้วยโค้ดทั้งหมด ไม่มีไฟล์ภาพและไม่มีโมเดล 3 มิติ
ทั้งเกมอยู่ในไฟล์เดียวคือ `engine/endless.html` (WebGPU + WGSL ไม่มีขั้นตอน build และไม่มี dependency)

## วิธีเปิด

ต้องใช้เบราว์เซอร์ที่รองรับ WebGPU (Chrome หรือ Edge รุ่นปัจจุบัน)

```
bun run serve
```

แล้วเปิด http://localhost:8080

ถ้าไม่มี bun ใช้เซิร์ฟเวอร์ไฟล์นิ่งตัวไหนก็ได้ชี้ไปที่โฟลเดอร์ `engine/` แล้วเปิด `endless.html`

## ปุ่ม

| ปุ่ม | การทำงาน |

| W A S D | ขับ |

| ลากเมาส์ | มองรอบ |
| P | ขับอัตโนมัติ เปิด/ปิด |

มุมซ้ายบนแสดง fps ความละเอียด จำนวนสามเหลี่ยม ชื่อโซน เวลา สภาพอากาศ ความเร็ว และเสียงที่กำลังเล่น
ถ้า fps ต่ำกว่า 34 เกมจะลดความละเอียดลงเองเพื่อให้ลื่น

## โลกในเกม

ถนนยาวไม่สิ้นสุด แบ่งเป็นช่วงละ 1.2 กม. แต่ละช่วงสุ่มว่าเป็นโซนอะไร จึงไม่มีลำดับตายตัว
(ยกเว้นช่วงต้นทางที่ล็อกไว้ให้เริ่มที่ถนนเลียบทะเล และมีเมืองอย่างน้อยทุก 4 ช่วง)

- **ถนนเขาและป่า** มีอ่างเก็บน้ำ ทุ่งหญ้าสีทอง และบางช่วงเป็นทางขึ้นเขาโค้งหักศอก
- **เมือง** ตึกแถว บ้าน ตึกสูง สายไฟ เสาไฟถนน และคลองตัดกลางเมืองพร้อมสะพาน
- **ถนนเลียบทะเล** สามแบบต่อกัน: ถนนบนหน้าผา แนวต้นสนทะเล และหาดเปิดที่มีมะพร้าว ร่ม เรือหางยาว เรือประมง สะพานไม้ เกาะไกลๆ
- **ทุ่งนา** แปลงนาสี่ระยะ บ้านมีรั้วไม้หรือรั้วปูน ศาลพระภูมิ ศาลาริมทาง แม่น้ำ คลอง และสะพาน
- **ทุ่งดอกไม้** แปลงดอกไม้สลับกับนาข้าว
- **ทุ่งหิมะ** พื้นและต้นไม้มีหิมะคลุม หิมะตก

ของริมทาง: หลักกิโล ป้ายเตือน ราวกันตก หลักนำโค้ง เสาไฟฟ้าและสายไฟ รั้วลวดหนาม

## เวลา อากาศ และเสียง

- วันหนึ่งยาว 12 นาที มีเช้า กลางวัน เย็น กลางคืน บางคืนไม่มีพระจันทร์ ไฟหน้าเปิดเองตอนมืด
- สภาพอากาศ: แดดจ้า เมฆมาก ฝนเบา ฝนหนัก ฝนฟ้าคะนองมีฟ้าแลบ หมอกบาง หมอกหนา สุ่มเปลี่ยนเองทุก 1.5–4 นาที หรือเลือกเอง
- ฝนทำให้ถนนเปียกเงา มีแอ่งน้ำสะท้อนฟ้า และใบไม้เปียก
- ลมแรงเบาไม่เท่ากันตามที่และเวลา ต้นไม้ หญ้า และนาข้าวไหวตาม
- เสียงสังเคราะห์ทั้งหมด: ลม คลื่นทะเล ฝน ฟ้าร้อง นกตอนเช้า จักจั่นตอนเย็น จิ้งหรีดตอนกลางคืน หมาเห่าหอนใกล้บ้านคนตอนกลางคืน

## เครื่องเล่นเพลง

แถบเล็กมุมขวาล่าง วางลิงก์ playlist หรือวิดีโอของ YouTube แล้วเล่นได้เลย เอาเมาส์ชี้เพื่อดูเวลา ความดัง และเปลี่ยนลิงก์
เกมจำลิงก์ล่าสุดไว้ในเบราว์เซอร์ ต้องต่ออินเทอร์เน็ต และเพลงที่เจ้าของไม่อนุญาตให้ฝังจะถูกข้าม

หมายเหตุ: ตัวเล่นวิดีโอของ YouTube ถูกซ่อนไว้หลังภาพเกม ซึ่งไม่ตรงกับเงื่อนไขการใช้งานของ YouTube ที่ให้ตัวเล่นมองเห็นได้
ถ้าจะเผยแพร่เกมควรเปลี่ยนเป็นแสดงตัวเล่น

## วิธีวาดภาพ

- ใบไม้และใบหญ้าทุกใบเป็นรูปทรงจริงแบบ instanced ปั้นทรงใน vertex shader ใบไม้ใบกว้างตัดเป็นช่อใบเล็กใน fragment shader
- เงาจาก shadow map ที่ตามกล้อง แสงทะลุใบไม้
- ภาพ HDR + MSAA ×4 แล้วผ่าน bloom และ tone map
- ลดรายละเอียดตามระยะ โดยวาดใบไม้แค่บางส่วนและให้ใบกว้างขึ้น
- พื้นดินสร้างเป็นชิ้น 64 เมตร ทีละชิ้นต่อเฟรม หญ้าปลูกเฉพาะรอบกล้อง

แนวคิดการวาดพืชด้วย instancing และลำดับ post-process ได้แรงบันดาลใจจากโปรเจกต์
[abyssal-garden](https://github.com/Noniv/abyssal-garden) (MIT) โค้ดทั้งหมดเขียนขึ้นใหม่

## โครงสร้าง

```
engine/endless.html   เกมทั้งหมด
scripts/serve.mjs     เซิร์ฟเวอร์สำหรับเปิดเล่นในเครื่อง
```

## ที่ยังไม่มี

- ตัวรถและห้องคนขับ (มีโค้ดอยู่ในไฟล์แต่ปิดไว้ด้วย `SHOW_CAR`)
- คนและรถคันอื่น
- การชนกับของริมทาง (ตอนนี้กันเฉพาะน้ำ ราวกันตก กำแพง ราวสะพาน และทางชัน)
