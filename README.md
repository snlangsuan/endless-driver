# Endless

เกมขับรถชมวิวแบบไม่มีจุดสิ้นสุด มุมมองบุคคลที่ 1 (three.js) — ถนน ภูมิประเทศ และวิวสองข้างทางสร้างขึ้นแบบ procedural ไปเรื่อย ๆ

## วิธีเล่น
- **เปิด `dist/index.html` ได้เลย** (ดับเบิลคลิก ไม่ต้องมีเซิร์ฟเวอร์)
- ใช้มือถือเป็นจอย: `bun run serve` แล้วเปิดเกมบนคอมที่ http://localhost:8080 จากนั้นสแกน QR ในหน้าเมนูของเกมด้วยมือถือ (Wi-Fi เดียวกัน) ครั้งแรกมือถือจะเตือนว่าการเชื่อมต่อไม่ปลอดภัย เพราะใช้ใบรับรองที่สร้างเองในเครื่อง ให้กด "แสดงรายละเอียด" แล้ว "เข้าชมเว็บไซต์นี้" (iPhone) หรือ "ขั้นสูง" แล้ว "ดำเนินการต่อ" (Android) หน้าจอยต้องเป็น https จึงจะเอียงมือถือเลี้ยวได้

## เลือกรถ
ในเมนู (เริ่มเกม หรือกด Esc / ปุ่มเมนู) เลือกได้ 7 คัน + 8 สี เกมจำค่าไว้ให้:
สปอร์ตคูเป้ (โรตารี 9,000 รอบ), เก๋ง (4 สูบ), แฮทช์แบ็ก (4 สูบเทอร์โบ), กระบะ (ดีเซล), SUV (V6), รถตู้ (ดีเซล), รถบรรทุก (ดีเซล 6 สูบ)
แต่ละคันมีเสียงเครื่อง น้ำหนัก แรงบิด รอบสูงสุด ความสูงที่นั่ง และขนาดตัวรถต่างกัน

## โซน (วนไปเรื่อย ๆ ทุก ~3.6 กม. เปลี่ยนแบบค่อยเป็นค่อยไป)
ทุ่งนาชนบท (ฤดูฝน) → ถนนเลียบชายทะเล (ฤดูร้อน) → ทุ่งดอกไม้ (ใบไม้ผลิ) → ป่าใบไม้เปลี่ยนสี (ใบไม้ร่วง) → ป่าสนบนภูเขา → ภูเขาหิมะ (ฤดูหนาว) → ทะเลทรายแคนยอน
- กลางวัน/กลางคืนหมุนเวียน (1 วัน = 12 นาทีจริง, กด T เร่งเวลาได้) — พระอาทิตย์ขึ้น/ตก ดาว พระจันทร์ ไฟถนน ไฟหน้ารถ
- สภาพอากาศตามโซน: ฝน (ที่ปัดน้ำฝนทำงาน), หิมะ, กลีบดอกไม้, ใบไม้ร่วง
- รถสวนทาง (ขับชิดซ้ายแบบไทย, รถพวงมาลัยขวา)
- ชนของข้างทางได้: ต้นไม้ใหญ่/บ้าน/เสา/หิน/ราวกันตกเป็นของแข็ง, หลักนำทาง/ป้าย/หลัก กม./พุ่มไม้ ชนแล้วล้ม, หญ้าผ่านได้
- เครื่องยนต์โรตารี 2 โรเตอร์ เรดไลน์ 9,000 รอบ: เสียงเดินเบาสะดุด, เสียงแหลมตอนลากรอบ, เทอร์โบหวีด, โบลว์ออฟ และเสียงป๊อกตอนถอนคันเร่ง
- กราฟิก: เงาแบบเรียลไทม์, tone mapping + bloom (แสงอาทิตย์/ไฟถนน/ไฟรถเรือง), ท้องฟ้าแสงพระอาทิตย์ตก/ทางช้างเผือก/พระจันทร์,
  เมฆหลายชั้น, ทะเลมีคลื่นสะท้อนแสง, ภูเขาไกลหลายระดับ, หญ้าและดอกไม้ไหวตามลม, ต้นไม้ไหว, นกบิน, หิ่งห้อยตอนกลางคืน,
  ถนนเปียกสะท้อนแสงตอนฝนตก, หยดน้ำบนกระจก + ที่ปัดน้ำฝน, ราวกันตกบนเขา, หมุดสะท้อนแสงกลางถนน
- รถละเอียด: เก๋ง, แฮทช์แบ็ก, กระบะ, SUV, รถตู้, รถบรรทุก (ตัวถังโค้ง กระจก ล้อแม็ก ไฟ ป้ายทะเบียน) สะท้อนท้องฟ้าจริง; รถของเราเป็นสปอร์ตคูเป้ fastback สีเหลือง (ออกแบบเอง) ล้อหมุนและเลี้ยวได้
- วิวละเอียด: ไผ่, กล้วย, เบิร์ช, ต้นไม้แห้ง, กระท่อมไม้, เจดีย์, เรือประมง, กังหันลม (หมุน), เสาไฟฟ้า + สายไฟ, ป้ายเตือนทางโค้ง, ป้ายจำกัดความเร็ว, หลัก กม.
- พื้นผิว: texture พื้นดิน/หิน 2 ระดับ + bump, ถนนความละเอียดสูง (กรวด รอยแตก รอยต่อ คราบน้ำมัน), ลายผิวใบไม้/เปลือกไม้

## ปุ่มคีย์บอร์ด
| ปุ่ม | การทำงาน |
|---|---|
| W/↑ · S/↓ · A D/← → | คันเร่ง · เบรก · เลี้ยว |
| Space | เบรกแรง |
| G | สลับเกียร์ **อัตโนมัติ (AT)** / **ธรรมดา (MT)** |
| E/Shift · Q/Ctrl | ขึ้นเกียร์ · ลดเกียร์ (MT: R-N-1…6) |
| AT: ค้าง S ตอนรถหยุด | สลับ D ↔ R (ถอยหลัง) |
| 1 / 2 / 3 / 4 | มองหน้า / ซ้าย / ขวา / หลัง |
| ลากเมาส์ (ดับเบิลคลิกกลับหน้า) | หันมองรอบ ๆ |
| C | กล้อง: ห้องคนขับ / ฝากระโปรง / นอกรถ |
| V | กระจก: ปิด → กระจกมองหลัง → กระจกมองหลัง + กระจกมองข้างซ้าย/ขวา (ภาพสะท้อนจริง) |
| P | ขับอัตโนมัติ (นั่งชมวิว) ไม่เกินความเร็วที่ตั้ง |
| R | ครูซคอนโทรลแบบ adaptive: รักษาความเร็ว, ตามรถคันหน้าโดยเว้นระยะ, เบรก = ยกเลิก |
| - / + | ตั้งความเร็ว (30-200 km/h) สำหรับขับอัตโนมัติและครูซ |
| N | ระยะห่างรถคันหน้า ใกล้ / กลาง / ไกล |
| Z / X | ไฟเลี้ยวซ้าย / ขวา (ดับเองหลังเลี้ยวเสร็จ) |
| B | ไฟฉุกเฉิน |
| H | บีบแตร (กดค้าง) รถคันใกล้ ๆ อาจบีบตอบ |
| L · T · J | ไฟหน้า · เร่งเวลา · ข้ามไปโซนถัดไป |
| K | คุณภาพกราฟิก ต่ำ / กลาง / สูง (เงา, bloom, หญ้า) — หรือกดเลือกที่แถบคุณภาพบนจอ |
| M · F · U · Esc | เสียง · เต็มจอ · ซ่อน HUD · เมนู |

มือถือ: พวงมาลัยซ้ายล่าง (หรือเอียงเครื่อง), คันเร่ง/เบรกขวาล่าง, ปุ่ม ▲▼ เปลี่ยนเกียร์ในโหมด MT, ปุ่มมอง สำหรับมองหน้า/ซ้าย/ขวา/หลัง, ลากนิ้วบนจอเพื่อหันมอง

## สร้างภาพ assets ด้วย Gemini (ไม่บังคับ)
1. คัดลอก `.env.example` เป็น `.env` แล้วใส่ `GEMINI_API_KEY=...`
2. `bun install` (ติดตั้ง sharp สำหรับแต่งภาพ)
3. `bun run gen:assets` สร้างทุกภาพที่ยังไม่มี หรือระบุชื่อ เช่น `bun run gen:assets grass rock`
   - `--list` ดูรายชื่อ, `--dry` ดู prompt โดยไม่เรียก API, `--force` สร้างใหม่ทับ, `--reprocess` แต่งภาพจากไฟล์ดิบเดิมโดยไม่เรียก API
4. เปิด `assets/preview.html` ตรวจภาพ (texture แสดงแบบปู 3x3 ให้เห็นรอยต่อ)

ผลลัพธ์อยู่ใน `assets/*.webp` (ภาพดิบจาก API เก็บใน `assets/raw/`)
5. `bun run build` ฝังภาพทั้งหมดลงใน `dist/index.html` อัตโนมัติ (ถ้าไม่มีโฟลเดอร์ assets เกมจะใช้ texture ที่วาดด้วยโค้ดแทน; ตั้ง `NO_ASSETS=1` เพื่อ build แบบไม่ฝังภาพ)

เกมใช้ภาพดังนี้: พื้นดินผสม texture 8 ชนิดตามภูมิประเทศ (หน้าผาใช้การฉายสามทิศทางไม่ให้ภาพยืด), ถนนใช้ยางมะตอยจริง, ขอบถนนใช้กรวด, ภูเขาไกลเปลี่ยนตามโซน (เขาเขียว/เขาหิมะ/เขาหัวตัด/เกาะหินปูน), เมฆใช้ภาพจริง
- texture พื้นผิว 10 แบบ: ทำให้ต่อกันไร้รอยต่ออัตโนมัติ
- ภูเขาไกล 4 แบบ: สร้างบนพื้นเขียวแล้วตัดเป็นพื้นหลังโปร่งใส
- เมฆ 6 แบบ: สร้างบนพื้นดำแล้วแปลงเป็นภาพโปร่งใส
- ต้นไม้/พืช 14 แบบ: สร้างบนพื้นชมพูบานเย็นแล้วตัดเป็นภาพโปร่งใส ใช้เป็นต้นไม้แบบแผ่นภาพไขว้ (billboard) แทนโมเดล low-poly
- พื้นผิวอาคาร 5 แบบ: ผนังไม้, ผนังซุง, กระเบื้องหลังคา, หลังคาสังกะสี, ผนังปูนขาว

## พัฒนาต่อ
ใช้ [Bun](https://bun.sh) (`curl -fsSL https://bun.sh/install | bash` หรือ `brew install oven-sh/bun/bun`)
```
bun install
bun run build   # รวม src/ เป็น dist/index.html ไฟล์เดียว (ใช้ Bun.build)
```
- `src/world.js` — noise, โซน/ฤดู, ถนนไม่สิ้นสุด, ความสูงภูมิประเทศ
- `src/models.js` — โมเดล low-poly (ต้นไม้, บ้าน, รถ, ห้องโดยสาร)
- `src/main.js` — เรนเดอร์, tile ภูมิประเทศ, ฟิสิกส์รถ + เกียร์, กล้อง, สภาพอากาศ, จราจร
- `src/sky.js` — ท้องฟ้า เมฆ ภูเขาไกล ทะเล · `src/post.js` — bloom/โทนสี · `src/veg.js` — หญ้า ดอกไม้ หิ่งห้อย นก
- `src/hud.js`, `src/audio.js` — หน้าปัด และเสียง (เครื่องโรตารี 2 โรเตอร์ + เทอร์โบ, ลม, ฝน, ดนตรีแอมเบียนต์)
