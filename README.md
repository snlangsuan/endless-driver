# Endless

เกมขับรถชมวิวแบบไม่มีจุดสิ้นสุด ทุกอย่างบนจอวาดด้วยโค้ดทั้งหมด ไม่มีไฟล์ภาพและไม่มีโมเดล 3 มิติ
เขียนด้วย WebGPU + WGSL ล้วน ไม่มีขั้นตอน build และไม่มี dependency โค้ดอยู่ใน `engine/` แยกไฟล์ตามส่วนงาน (ดูหัวข้อโครงสร้างไฟล์)

## วิธีเปิด

ต้องใช้เบราว์เซอร์ที่รองรับ WebGPU (Chrome หรือ Edge รุ่นปัจจุบัน)

```
bun run serve
```

แล้วเปิด http://localhost:8080 (Endless) หรือ http://localhost:8080/ruin (Ruin เมืองร้างหลังวันสิ้นโลก ดูหัวข้อ Ruin ด้านล่าง)

ถ้าไม่มี bun ใช้เซิร์ฟเวอร์ไฟล์นิ่งตัวไหนก็ได้ชี้ไปที่โฟลเดอร์ `engine/` แล้วเปิด `endless.html`

ต้องเปิดผ่านเซิร์ฟเวอร์เสมอ เปิดไฟล์ตรงๆ แบบ `file://` ไม่ได้ เพราะหน้าเกมต้องโหลดไฟล์ shader

วางบน GitHub Pages ได้เลย (ตั้งให้เผยแพร่จาก branch ที่ root) `index.html` ที่ root จะพาไปที่ `engine/endless.html`

## โครงสร้างไฟล์

```
index.html            พาไปที่ engine/endless.html (สำหรับ GitHub Pages)
scripts/serve.mjs     เซิร์ฟเวอร์สำหรับเล่นบนเครื่อง เสิร์ฟทุกไฟล์ใน engine/
engine/
  endless.html        หน้าของ Endless: canvas แถบข้อความ เครื่องเล่นเพลง
  ruin.html           หน้าของ Ruin: โครงเดียวกัน เพิ่มแผนที่ และบอก boot.js ว่าใช้ไฟล์ชุดไหน (window.GAME)
  endless.css         หน้าตาของแถบข้อความและเครื่องเล่นเพลง
  shaders/
    common.wgsl       ใช้ร่วมทุก shader: ค่าที่ส่งจากเกม noise ลายพื้น ลม รูปทรงใบไม้และกิ่ง
    land.wgsl         ผืนดินของ Endless ฝั่ง shader: ถนนและโซน (ต้องตรงกับ src/land.js)
    vertex.wgsl       จัดรูปพื้น ใบไม้ กิ่ง กล่อง
    terrain.wgsl      ลงสีพื้นของ Endless: ถนน นา เมือง หาด และทะเล
    scene.wgsl        ลงสีส่วนที่เหลือ: เงา ฟ้า ใบไม้ กิ่ง บ้านและป้าย
    post.wgsl         แสงฟุ้ง
    final.wgsl        ปรับโทนภาพ เส้นฝนและหิมะ
  src/                โหลดตามลำดับนี้
    boot.js           แสดง error ขออุปกรณ์กราฟิก โหลด shader แล้วโหลดไฟล์ที่เหลือ (รายการไฟล์เปลี่ยนได้ด้วย window.GAME)
    core.js           canvas ค่าคงที่ ฟังก์ชันคณิตศาสตร์เล็กๆ noise และตัวสุ่ม
    land.js           ถนน โซน ความสูงพื้น แม่น้ำ (ของ Endless)
    shaders.js        ประกอบและคอมไพล์ shader
    render.js         pipeline และ render target
    plants.js         ต้นไม้ทุกชนิด
    buildings.js      บ้าน ศาล และของที่ประกอบจากกล่อง
    chunks.js         สร้างโลกทีละช่อง: วางต้นไม้ บ้าน เมือง ของริมทาง (ของ Endless)
    weather.js        เวลาและสภาพอากาศ
    input.js          ปุ่ม เมาส์ แผงตั้งค่า กล้อง
    sound.js          เสียง
    car.js            ตัวรถ (ปิดการแสดงอยู่)
    music.js          เครื่องเล่นเพลงจาก YouTube
    collide.js        อะไรขวางรถ และพุ่มไม้ที่รถทับ
    drive.js          การขับและขับอัตโนมัติบนถนนเส้นเดียว ข้อความมุมซ้ายบน (ของ Endless)
    main.js           วาดแต่ละเฟรม
  ruin/               ส่วนที่เป็นของ Ruin เอง (ใช้แทนไฟล์ "ของ Endless" ข้างบน)
    land.js           แผนที่ 20 × 20 กม.: ขอบเขตเมือง แม่น้ำ ตารางถนน สะพาน ความสูงพื้น
    land.wgsl         ผืนดินเดียวกันฝั่ง shader (ต้องตรงกับ ruin/land.js)
    terrain.wgsl      ลงสีพื้น: ยางมะตอยแตกร้าว เส้นจราจรซีด วัชพืช ทางเท้า คราบเลือด แม่น้ำ
    world.js          สร้างโลกทีละช่อง: ตึกสูง ตึกแถว บ้าน โกดัง ซากรถ ค่ายทหาร สะพาน ป่า
    game.js           การขับ ซอมบี้ สภาพรถ แผนที่ใหญ่ ตัวเลข fps
    ruin.css          ซ่อนปุ่มและแถบของหน้า Endless หน้าตาของแผนที่และข้อความแจ้ง
```

ไฟล์ใน `src/` เป็นสคริปต์ธรรมดาที่ใช้ scope เดียวกัน (ไม่ใช่ ES module) ชื่อที่ประกาศบนสุดของไฟล์หนึ่งใช้ได้ในไฟล์ถัดไปทั้งหมด
ลำดับการโหลดจึงสำคัญ และกำหนดไว้ใน `PARTS` ของ `src/boot.js` (หน้าเกมอื่นกำหนดรายการของตัวเองได้ด้วย `window.GAME` ก่อนโหลด `boot.js` ดู `engine/ruin.html`)

|---|---|
| W A S D | ขับ |

| T | ข้ามเวลา (เช้า กลางวัน เย็น กลางคืน) |
| R | เลือกสภาพอากาศแบบถัดไป |
| Y | สุ่มสภาพอากาศอัตโนมัติ เปิด/ปิด |
| L | ไฟหน้า |
| F | กล้องบิน (Q/E ลง/ขึ้น) |
| V | มองรถจากด้านหลัง / กลับเข้าที่นั่งคนขับ |
| M | เสียงเกม เปิด/ปิด |
| G | เต็มจอ / กลับขนาดปกติ |

มุมซ้ายบนแสดง fps ความละเอียด จำนวนสามเหลี่ยม ชื่อโซน เวลา สภาพอากาศ ความเร็ว และเสียงที่กำลังเล่น
ถ้า fps ต่ำ เกมจะลดความละเอียดลงเองเพื่อให้ลื่น (เทียบกับอัตราที่ดีที่สุดที่จอนั้นทำได้ จอ 30 หรือ 50 Hz จึงไม่ถูกลดโดยไม่จำเป็น)

คุณภาพภาพเลือกได้ในแผงตั้งค่า (ปุ่มเฟืองมุมขวาบน) มี 4 ระดับ

| ระดับ | ความละเอียดที่วาด | ใบไม้ กิ่ง และหญ้าเต็มไปไกลแค่ไหน | ตอน fps ตก |
|---|---|---|---|
| ต่ำ | 75% ของจอ | 60% | ย่อได้ถึง 50% และพยายามรักษา 60 fps |
| กลาง | เท่าจอ | 80% | ย่อได้ถึง 75% และพยายามรักษา 60 fps |
| สูง (ค่าเริ่มต้น) | บนจอ 1x วาดใหญ่กว่าจอ 1.5 เท่าเมื่อเครื่องไหว | 100% | เลิกวาดใหญ่ก่อน แล้วย่อได้ถึง 80% |
| อัลตร้า | ใหญ่กว่าจอได้ถึง 2 เท่า (จอ 1080p วาดได้ถึง 3840x2160) | ใบไม้ 125% หญ้า 120% | ย่อลงจนได้ 30 fps ต่ำสุดเท่าขนาดจอ |

อัลตร้ายังเพิ่มเงาละเอียดขึ้นเท่าตัว (shadow map 8192 ราว 2.3 ซม. ต่อจุด) ขอบเงานุ่มแบบแสงแดดจริง เงาบนรถและใบไม้ใกล้ ๆ นุ่มด้วย ผิวถนนและดินมีรายละเอียดเม็ดหินระยะใกล้ ใบไม้ระยะกลางโค้งละเอียด และพื้นผิวรถคมขึ้น การเปลี่ยนเข้าหรือออกจากอัลตร้าจะโหลดหน้าใหม่เอง (รถ เวลา และสภาพอากาศอยู่ที่เดิม)

ไม่ว่าระดับไหน เกมจะไม่ลดจำนวนต้นไม้หรือความทึบของพุ่มไม้เพื่อเพิ่ม fps ใบไม้ไกล ๆ วาดน้อยใบลงแต่แต่ละใบใหญ่ขึ้น พุ่มจึงทึบเท่าเดิม

## โลกในเกม

ถนนยาวไม่สิ้นสุด แบ่งเป็นช่วงละ 1.2 กม. แต่ละช่วงสุ่มว่าเป็นโซนอะไร จึงไม่มีลำดับตายตัว
(มีเมืองอย่างน้อยทุก 4 ช่วง) จุดเริ่มสุ่มใหม่ทุกครั้งในระยะราว 14 กม. จากจุดกำเนิดของโลก
เมืองแต่ละแห่งยาวไม่เท่ากัน สุ่มตั้งแต่ราว 800 ม. ถึงเกือบ 3 กม. และถ้าช่วงถัดไปเป็นทุ่งนา เมืองอาจยาวข้ามเข้าไปในช่วงนั้นได้

- **ถนนเขาและป่า** ป่าขึ้นเป็นหย่อมแน่นสลับที่โล่ง มีไม้พุ่มและกล้วยป่าใต้ต้นไม้ริมทาง อ่างเก็บน้ำ ทุ่งหญ้าสีทองในที่โล่ง และบางช่วงเป็นทางขึ้นเขาโค้งหักศอก
- **อุโมงค์ลอดเขา** ถนนเขาช่วงที่ไม่มีโค้งหักศอกจะมีภูเขาขวางกลางช่วง ถนนลอดผ่านในอุโมงค์ยาว 220–320 ม. มีไฟตลอดอุโมงค์และปากอุโมงค์คอนกรีตสองด้าน
- **ทางลอดในเมือง** สี่แยกในเมืองราวครึ่งหนึ่ง ถนนใหญ่ลาดลงไปในร่องระหว่างกำแพงคอนกรีต ลอดใต้ถนนตัดแล้วไต่กลับขึ้นมา (สี่แยกที่เหลือเป็นไฟจราจร) ขับบนถนนตัดข้ามด้านบนได้ด้วย
- **สะพานแขวนข้ามไปเกาะ** บางช่วงถนนข้ามทะเลไปยังเกาะกลางน้ำด้วยสะพานแขวนสองสะพาน สะพานละ 370 ม. มีเสาสูง สายเคเบิลหลัก และสายแขวน บนเกาะมีหมู่บ้านชาวประมง บ้านไม้ยกพื้นสองแถว และท่าเรือไม้ยื่นลงทะเลข้างเชิงสะพาน (ขับลงหาดขึ้นไปบนท่าเรือได้)
- **ถนนพญาเสือโคร่ง** ถนนเขาบางช่วงมีพญาเสือโคร่งออกดอกสีชมพูเรียงสองข้างทาง กิ่งโค้งมาบรรจบกันเหนือถนนเป็นซุ้มให้รถลอดผ่าน และขึ้นเป็นส่วนใหญ่ของป่าทั้งเขา (มองจากไกลก็เป็นสีชมพู)
  ทุ่งนาบางช่วงก็มีซุ้มพญาเสือโคร่งบนทางราบ มีกลีบดอกร่วงบนพื้นและปลิวลงมาในอากาศ ช่วงนี้นับเป็นหน้าหนาว
- **เมือง** ตึกแถวที่หน้าร้านเปิดลึกเข้าไปจริง (ร้านชำ ร้านอาหาร ร้านทอง ร้านหน้ากระจกติดแอร์ ร้านซ่อมมอเตอร์ไซค์ หรือปิดประตูม้วน)
  ห้องแถวไม้ในเมืองเก่า เหล็กดัด ผ้าใบกันสาด ผ้าตาก ของต่อเติมบนดาดฟ้าและหลังตึก มอเตอร์ไซค์จอดริมทาง
  ซอยแยกจากถนนทุก 36 ม. มีบ้านเรียงสองฝั่งในรั้วปูนกับประตูเหล็ก ที่ว่างรกร้าง และแฟลต
  ป้ายจำกัดความเร็ว 50 และป้ายชื่อเมืองริมทางก่อนเข้าเมือง (ไม่มีอะไรคร่อมถนน) ทางม้าลาย ขอบทางทาสี ตลาด วัด ปั๊มน้ำมัน ร้านสะดวกซื้อ 24 ชม. (แบรนด์สมมติ "1 มาร์ท") สายไฟ เสาไฟถนน และคลองตัดกลางเมืองพร้อมสะพาน
- **ถนนเลียบทะเล** สามแบบต่อกัน: ถนนบนหน้าผา แนวต้นสนทะเล และหาดเปิดที่มีมะพร้าว ร่ม เรือหางยาว เรือประมง สะพานไม้ เกาะไกลๆ
- **ทุ่งนา** แปลงนาสี่ระยะ บ้านมีรั้วไม้หรือรั้วปูน ศาลพระภูมิ ศาลาริมทาง แม่น้ำ คลอง และสะพาน
- **ทุ่งดอกไม้** แปลงดาวเรืองและคอสมอสสลับกับนาข้าว แปลงเริ่มห่างถนนแค่ 14 ม. (ช่วงอื่นของทุ่งนาเริ่มที่ 48 ม.) หัวดอกหันเข้าหาผู้มอง และแปลงไกลๆ เห็นเป็นผืนสี
- **ทุ่งหิมะ** พื้นและต้นไม้มีหิมะคลุม หิมะตก

ของริมทาง: ป้ายเตือน ราวกันตก หลักนำโค้ง รั้วลวดหนาม
- หลักกิโลเมตรทุก 1 กม. ทางซ้าย เป็นเสาขาวยอดจั่ว ด้านหน้ามีเครื่องหมาย เลขทางหลวง และเลขกิโลเมตร ด้านข้างมีระยะทาง
- สายไฟต่อเนื่องจากเสาถึงเสาเสมอ ข้ามแม่น้ำและคลองเป็นช่วงยาวข้างสะพาน
- เสาไฟฟ้าคอนกรีตสี่เหลี่ยมสูง 10 ม. ทุก 40 ม. มีคอนกับลูกถ้วยสามลูกสำหรับสายแรงสูง และสายดินเหนือยอดเสา
  ในเมืองและช่วงที่มีหมู่บ้านมีสายแรงต่ำสี่เส้นเรียงแนวตั้งกับมัดสายสื่อสารเพิ่ม

## รถ

รถครอสโอเวอร์สีแดง ไม่มียี่ห้อ สร้างด้วยโค้ดทั้งคัน ตัวถังเป็นผิวเดียวขึงบนหน้าตัดตามแนวยาว โดยเส้นหลังคา ความกว้าง และแนวขอบกระจก
วัดมาจากโมเดลอ้างอิงที่เจ้าของโปรเจกต์ให้มา (วัดสัดส่วน ไม่ได้คัดลอกโมเดล) มองจากที่นั่งคนขับเห็นฝากระโปรง เสา แผงหน้าปัด พวงมาลัย และกระจกมองข้าง
ปิดรถได้ด้วย `SHOW_CAR` ในโค้ด

## เวลา อากาศ และเสียง

## วิธีวาดภาพ

- ใบไม้และใบหญ้าทุกใบเป็นรูปทรงจริงแบบ instanced ปั้นทรงใน vertex shader ใบไม้ใบกว้างตัดเป็นช่อใบเล็กใน fragment shader

- พื้นดินสร้างเป็นชิ้น 64 เมตร ทีละชิ้นต่อเฟรม หญ้าปลูกเฉพาะรอบกล้อง
- พื้นดินไม่มีไฟล์ลาย: ผืนหญ้าวาดเป็นเส้นใบหลายทิศบนเศษหญ้าแห้งสีเข้ม ขอบหญ้าแหว่งเป็นกอ ดินมีเม็ดกรวด รอยแตก ใบไม้แห้ง และฝุ่นซีด
  รายละเอียดเล็กจางหายเกิน 60 เมตร และใบหญ้าจริงปลูกตามกฎเดียวกับสีพื้น จึงขึ้นตรงผืนหญ้าพอดี ไม่ขึ้นบนดินโล่ง

แนวคิดการวาดพืชด้วย instancing และลำดับ post-process ได้แรงบันดาลใจจากโปรเจกต์

## Ruin (เมืองร้าง)

เกมที่สองบน engine เดียวกัน: ขับรถสำรวจเมืองร้างหลังวันสิ้นโลกจากภัยพิบัติซอมบี้ เปิดที่ http://localhost:8080/ruin (หรือ `engine/ruin.html` บน GitHub Pages)

**แผนที่และอัตราส่วน** แผนที่ 20 × 20 กม. = 400 ตร.กม. ใช้อัตราส่วน 1:1 คือ 1 เมตรในเกมเท่ากับ 1 เมตรจริง (โลกสร้างทีละช่อง 64 ม. เฉพาะรอบตัว จึงไม่ต้องย่อ)
มองเห็นได้ไกลราว 360 ม. ก่อนจมหมอก ขับข้ามแผนที่จากขอบถึงขอบที่ 90 km/h ใช้ราว 13 นาที จุดกลางแผนที่คือพิกัด 0, 0 (แกน x ไปทางตะวันออก แกน z ไปทางเหนือ)

- **ตัวเมือง** รูปสี่เหลี่ยมมุมมนกว้างราว 13 กม. กลางแผนที่ (ราว 40% ของพื้นที่) ขอบเมืองเว้าแหว่งไม่เป็นเส้นตรง
  ใจกลางเป็นย่านตึกสูง (รัศมีราว 2.5 กม.) ถัดออกมาเป็นย่านการค้าตึกแถวและแฟลต แล้วเป็นย่านบ้านพักอาศัย แทรกด้วยสวนสาธารณะร้าง ลานจอดรถ โกดัง และค่ายทหารที่ถูกทิ้ง
- **ถนน** เป็นตาราง ทุก 128 ม. มีถนนหนึ่งเส้น (หนึ่งบล็อก = 2 × 2 ช่องของโลก) ทุกเส้นที่ 8 เป็นถนนสายหลัก 4 เลน ห่างกัน 1,024 ม.
  ถนนซอยมีเฉพาะที่เมืองหนาแน่นพอ นอกเมืองเหลือถนนสายหลักเส้นเว้นเส้น (ห่างกัน 2 กม.) และคดเคี้ยวเล็กน้อย
- **แม่น้ำ** กว้าง 65–105 ม. ไหลจากตะวันตกไปตะวันออกตลอดแผนที่ ผ่านครึ่งเหนือของเมือง (ระหว่าง z = 1.1 ถึง 2.0 กม.)
  ถนนสายหลักแนวเหนือ-ใต้ข้ามด้วยสะพานคอนกรีต 15 แห่ง ในจำนวนนี้ 4 แห่งขาดกลาง (สะพานที่ x = 0 บนเส้นทางจากจุดเริ่มใช้ได้เสมอ) ถนนซอยสุดที่ริมตลิ่ง
- **ป่า** ล้อมเมืองทุกด้าน กว้าง 3–4 กม. เป็นเนินเขา ป่าทึบสลับทุ่งร้าง ถนนออกนอกเมืองไต่เนินตามภูมิประเทศ
- **ขอบแผนที่** ภูเขาสูงขึ้นรอบด้าน ปลายถนนทุกเส้นมีกำแพงคอนกรีตแนวกักกันขวาง รถไปได้ไม่เกิน 9.9 กม. จากกลางแผนที่

**ความร้าง** ไม่มีไฟฟ้า ไม่มีไฟถนนหรือหน้าต่างสว่างตอนกลางคืน (เหลือแต่ไฟหน้ารถและแสงจันทร์) กระจกแตก หน้าต่างปิดไม้ คราบเขม่าเหนือหน้าต่างที่ไฟไหม้
คราบน้ำฝนและเถาวัลย์ไต่ผนัง ตึกบางหลังถล่มเหลือครึ่งหรือเอียง ซากรถจอดทิ้ง ชนกัน หรือไหม้ดำ สนิมกินเหล็ก เสาไฟล้ม ยางมะตอยแตกมีหญ้าและพุ่มไม้ขึ้นทะลุ
เส้นจราจรซีดหาย ทางเท้าแตก และคราบเลือดแห้งบนถนน

**ซอมบี้** เดินอยู่รอบตัวรถได้ถึง 56 ตัว (ในเมืองมาก ในป่าน้อย) ยืนหรือเดินเรื่อยเปื่อยจนกว่ารถจะเข้าใกล้หรือวิ่งเร็วจนได้ยิน แล้วจะเดินเข้าหา ส่วนน้อยวิ่งเร็ว
ชนด้วยความเร็วเกิน 9 km/h ซอมบี้ล้ม ถ้ารถจอดหรือคลาน ซอมบี้จะรุมทุบและสภาพรถลดลง ชนของแข็งแรงๆ ก็ลดเช่นกัน สภาพรถฟื้นช้าๆ เมื่อไม่มีซอมบี้ในระยะ 60 ม.
สภาพรถหมดจะกลับไปเริ่มที่จุดเริ่มต้น (ถนนสายหลักที่ x = 0 ห่างใจกลางเมืองไปทางใต้ 5.2 กม.) เกมเริ่มตอนบ่ายแก่วันฟ้าครึ้ม

**หน้าจอ** โล่งทั้งจอ: มีแค่ตัวเลข fps มุมซ้ายบนกับปุ่มเต็มจอมุมขวาบน ไม่มีเครื่องเล่นเพลง ปุ่มตั้งค่า นาฬิกา หรือแถบบอกปุ่ม (ซ่อนด้วย `ruin/ruin.css` และไม่โหลด `music.js`)
กด Tab เพื่อดูแผนที่ทั้ง 400 ตร.กม. พร้อมตำแหน่งรถ ถนนสายหลัก และสะพาน (แดง = ขาด) ข้อความแจ้งสั้นๆ ขึ้นกลางจอเมื่อเริ่มเกมและเมื่อรถพัง

| ปุ่ม | การทำงาน |
|---|---|
| W A S D | ขับ (ขับออกนอกถนนได้ทุกที่ แต่ช้าและสะเทือน) |
| Shift | เร่ง |
| Tab | แผนที่ใหญ่ เปิด/ปิด |
| T · R · Y · L · F · M · G · H | เหมือน Endless: ข้ามเวลา เลือกอากาศ สุ่มอากาศ ไฟหน้า กล้องบิน เสียง เต็มจอ ซ่อนข้อความ |

ไม่มีขับอัตโนมัติในเกมนี้ และไม่มีแผงเวลา/อากาศ/ตั้งค่าบนจอ ใช้ปุ่มลัดในตารางแทน

**ใช้ engine ร่วมกันอย่างไร** `ruin.html` ตั้ง `window.GAME` ให้ `boot.js` โหลด `ruin/land`, `ruin/world`, `ruin/game` แทน `land`, `chunks`, `drive` และใช้ `ruin/land.wgsl`, `ruin/terrain.wgsl`
แทน shader ผืนดินของ Endless ส่วนที่เหลือ (ตัววาด เงา ฟ้า อากาศ ต้นไม้ บ้าน วัสดุกล่อง เสียง) เป็นไฟล์ชุดเดียวกับ Endless
สิ่งที่เพิ่มใน engine เพื่อการนี้: `EXTRA` (กล่องที่ขยับได้ ส่งเข้า GPU ทุกเฟรม ใช้วาดซอมบี้) `gameTick` (งานของเกมต่อเฟรม) `hudText` (กำหนดข้อความมุมซ้ายบนเอง) `deadWorld` (ดับไฟทั้งโลกและทำให้ผนังเก่าโทรม)
และวัสดุกล่องใหม่สองแบบ: 50 สีพื้นตามที่กำหนด 51 พื้นสะพาน 4 เลน

ที่ยังไม่มีใน Ruin: เป้าหมายของเกม (ตอนนี้คือสำรวจและเอาตัวรอด) ของให้เก็บ น้ำมัน คนรอดชีวิต ภายในอาคาร และเส้นขอบฟ้าของตึกที่อยู่ไกลเกินระยะหมอก

## ลอยกระทง

หน้าแยกอีกหน้าหนึ่ง: คืนวันเพ็ญเดือนสิบสองที่วัดริมแม่น้ำ เดินด้วยมุมมองบุคคลที่หนึ่ง

ไฟล์ของหน้านี้มีสองไฟล์ใน `engine/`: `loykrathong.html` (วัด แม่น้ำ กระทง โคม คน เสียง) และ `engine.js` (ตัววาด: การเปิด WebGPU, shader, pipeline,
render target, ตัวสร้างต้นไม้) `engine.js` แยกออกมาจาก engine ของ Endless รุ่นก่อนที่ Endless จะแตกเป็น `src/` กับ `shaders/` ตอนนี้หน้านี้ยังไม่ได้ใช้
ไฟล์ใน `src/` ร่วมกับ Endless ของใหม่ที่เพิ่มใน Endless จึงยังไม่มาถึงหน้านี้ ส่วน shader เฉพาะของหน้านี้เสียบเข้า `engine.js` ผ่านตัวแปร `WGSL` (9 ช่อง อธิบายที่หัวไฟล์ `engine.js`)
เปิดด้วย `bun run serve` แล้วไปที่ http://localhost:8080/loykrathong (หรือเปิดไฟล์ `engine/loykrathong.html` ตรงๆ โดยมี `engine.js` อยู่ข้างกัน)

ลำดับ: เลือกกระทงที่ร้านในลานวัด (มองที่กระทงแล้วกด E) → ถือไปที่ท่าน้ำ → กด E จุดเทียนและธูป → กด Space ค้างเพื่ออธิษฐาน → กด E ลอยกระทง
จากนั้นไปหยิบโคมลอยที่ลานโคม กด Space ค้างให้ลมร้อนเต็มโคมแล้วโคมจะลอยขึ้นเอง ทำซ้ำได้ทั้งสองอย่าง

| ปุ่ม | การทำงาน |
|---|---|
| W A S D | เดิน |
| Shift | เดินเร็ว |
| เมาส์ | มองรอบ (คลิกที่ภาพเพื่อจับเมาส์ Esc ปล่อย หรือลากเมาส์ก็ได้) |
| E | หยิบ / ใช้ |
| Space ค้าง | อธิษฐาน / เติมลมร้อนให้โคม |
| M | เสียง เปิด/ปิด |

บนมือถือหรือแท็บเล็ต (หรือเมื่อแตะจอครั้งแรก) จะมีปุ่มบนจอแทน: ลากฝั่งซ้ายของจอเพื่อเดิน (ดันสุดขอบเพื่อเดินเร็ว) ลากฝั่งขวาเพื่อมองรอบ
ปุ่ม "ใช้" แทน E และปุ่ม "กดค้าง" แทน Space และหน้าจะใช้โหมดวาดแบบเบาเอง: ไม่มี MSAA เงาวาดครั้งเดียวตอนเริ่ม ไฟ 10 ดวงแทน 40 ต้นไม้ราวครึ่งเดียวและใบบางลง กระทง 50 ใบ ความละเอียดต่ำลง
บังคับโหมดได้ด้วย `?q=low` หรือ `?q=high` ต่อท้าย URL มุมซ้ายล่างของจอมือถือแสดง fps และความละเอียด
ต้องใช้เบราว์เซอร์มือถือที่รองรับ WebGPU

ป้ายด้านบนชี้ทางไปลานโคมตั้งแต่ต้นคู่กับเป้าหมายหลัก จนกว่าจะปล่อยโคมใบแรก พลุมีเสียงหวีดตอนพุ่งขึ้น เสียงระเบิด เสียงสะท้อน และเสียงแตกประกาย

เพลงประกอบ: หน้านี้สังเคราะห์เสียงขิมเล่นทำนองสองท่อนแรกของเพลงรำวงวันลอยกระทง (จากแท็บคาลิมบาที่เจ้าของโปรเจกต์ให้มา ใช้แบบไม่เชิงพาณิชย์)
มีฉิ่งกับโทนคุมจังหวะ วนไปตลอดงาน และเบาลงตอนอธิษฐาน ทำนองเขียนเป็นโน้ตไทยในตัวแปร `NOTES` ของ `engine/loykrathong.html`
(ด ร ม ฟ ซ ล ท ตัวละครึ่งจังหวะ, `'` สูงขึ้นหนึ่งช่วงคู่แปด, `,` ต่ำลง, `-` ลากเสียง, `x` หยุด) ปิดฉิ่งกับโทนได้ด้วย `DRUMS = false`
ถ้าวางไฟล์เสียงของคุณเองไว้ที่ `engine/loykrathong.mp3` หน้าจะเล่นไฟล์นั้นวนแทน

ในงาน: ซุ้มประตูและกำแพงวัด อุโบสถพร้อมใบเสมา เจดีย์ขาวห่มผ้าเหลืองมีเทียนรอบฐาน แถวร้านค้า (ร้านกระทงมีสี่แบบ: ใบตอง ดอกบัว ขนมปัง กล้วยไม้)
ราวโคมกระดาษและไฟประดับเหนือทางเดิน ต้นจามจุรีแขวนโคม ศาลาท่าน้ำ สะพานไม้ลงโป๊ะ เรือหางยาว กระทงราว 150 ใบลอยตามน้ำ
โคมลอยบนฟ้า พลุฝั่งตรงข้าม และพระจันทร์เต็มดวงสะท้อนน้ำ เสียงสังเคราะห์ทั้งหมด (จิ้งหรีด น้ำ ขิม ระฆัง พลุ เสียงเท้า)

ที่เพิ่มจาก engine เดิม: ไฟดวงเล็กหลายดวงส่องพื้นและของรอบตัว (เลือก 40 ดวงที่ใกล้ที่สุดต่อเฟรม) ผิวน้ำที่สะท้อนไฟเหล่านั้นกับพระจันทร์
แสงเทียนบนน้ำใต้กระทงแต่ละใบ และของที่ขยับได้ (กระทง โคมลอย) ส่งเข้า GPU ใหม่ทุกเฟรม
ส่วน shader ใบไม้ กิ่ง กล่อง เงา bloom และต้นไม้ มาจาก `engine.js`

คนในงาน: ราว 65 คน (โหมดเบาราว 30) เป็นคนทรงกล่อง แต่ละคนประกอบจากกล่องของ engine 8-9 ชิ้น (หัว ตัว แขน ขา และผ้าซิ่นสำหรับบางคน)
หน้า ผม เสื้อผ้า และสีผิววาดด้วย shader มีแม่ค้าหลังร้านทุกร้าน คนซื้อของ คนยืนคุยเป็นกลุ่ม คนยืนดูแม่น้ำและดูโคมที่ลาน
และคนเดินเที่ยวไปตามทางเดิน คนเดินจะหลบผู้เล่น หลบเสา และหลบกันเอง คนที่ยืนอยู่จะหันหน้ามามองเมื่อเดินเข้าใกล้
คนเดินบางคนทำอย่างที่ผู้เล่นทำ: แวะซื้อกระทงที่ร้านกระทง ถือเดินไปท่าน้ำ คุกเข่าที่ขอบโป๊ะ จุดเทียน ก้มอธิษฐาน ปล่อยกระทงลงน้ำ แล้วเดินกลับเข้างาน
(ที่ขอบโป๊ะมีที่ให้สี่คน เว้นตรงกลางไว้ให้ผู้เล่น ถ้าเต็มคนที่มาทีหลังจะยืนรอ)
โหมดเบาสำหรับมือถือ: คนที่อยู่ไกลเกิน 20 ม. วาดแบบหยาบ (ไม่มีแขน ขาเป็นแท่งเดียว) ไกลเกิน 80 ม. ไม่วาด ไม่วาดเงาของคน และกระทงในมือวาดแบบย่อเมื่อไกลเกิน 14 ม.
โค้ดอยู่ในส่วน `the people` ของ `engine/loykrathong.html` (จุดที่คนเดินไปคือ `PNODE` ทางเชื่อมคือ `PLINK`)

ที่ยังไม่มีในหน้านี้: มือของผู้เล่น และคนนั่ง

## ที่ยังไม่มี

- คนและรถที่วิ่งอยู่ (มีแต่รถกระบะและมอเตอร์ไซค์ที่จอดในเมือง)
- การชนกับของริมทาง (ตอนนี้กันเฉพาะน้ำ ราวกันตก กำแพง ราวสะพาน และทางชัน)
